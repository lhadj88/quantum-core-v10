# Yuga Remotion Studio Cloud v1

Production publicitaire verticale 2,5D entièrement rendue dans GitHub Actions.

## Masters
- `YugaStudioFR` — 1080×1920, 30 fps, 36 s
- `YugaStudioEN` — 1080×1920, 30 fps, 36 s

## Direction
- cartographie méditerranéenne
- trois chronologies animées
- seuil 2044–2082
- méthode épistémique
- livre en perspective 3D CSS, avec reconstruction vectorielle fidèle aux couvertures fournies
- sound design original sans bibliothèque externe

## Exécution
Le workflow `.github/workflows/yuga-remotion-studio-render.yml` rend les deux MP4 natifs, huit frames de contrôle, une planche QC, les rapports `ffprobe` et les SHA-256.
